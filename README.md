## 🃏 Cards Included

| File | Card Type | Description |
|------|-----------|-------------|
| `profile-card.html` | Profile | Avatar, name, role, bio, social links |
| `stat-card.html` | Stat / Metric | Label, value, trend indicator |
| `pricing-card.html` | Pricing | Free / Pro / Enterprise with featured highlight |
| `notification-card.html` | Notification | Icon, title, message, timestamp, unread state |
| `product-card.html` | Product | Image, name, description, price, button |
| `link-card.html` | Link / Article | Tag badge, title, excerpt, source meta |

---

## 🚀 How to Use

1. Browse the `/cards` folder
2. Open the card you want in your browser to preview it
3. Copy the HTML and CSS into your own project
4. Customize colors, text, and content to fit your needs

No install. No build step. No dependencies.
